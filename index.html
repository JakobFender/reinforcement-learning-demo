What to try

  1. The defaults reproduce Fig. 2.2: greedy (ε = 0) gets stuck near reward 1.0 and picks the best arm only about a third of the time. ε = 0.1 learns fastest (≈ 1.4). ε = 0.01 learns slowly, but over a much longer run (e.g. 2000 steps) it closes the gap.
  2. Click Preset: Fig. 2.3. Optimistic greedy (Q₀ = +5, α = 0.1) explores at the start because each arm it pulls disappoints it. Look at the spike in % optimal action around step 10.
  3. Set runs = 1, press Reset, then press Step a few times. The bar chart shows that Q(a) only moves toward q*(a) for arms the agent actually pulls. Then raise k to 20 and see exploration get more expensive.

Update rules

ε-greedy: Aₜ = argmaxₐ Qₜ(a) with prob. 1−ε, else a uniformly random arm
Reward: Rₜ ~ N(q*(Aₜ), 1), testbed q*(a) ~ N(0, 1)
Incremental mean (sample average): Qₙ₊₁ = Qₙ + (1/n)·[Rₙ − Qₙ]
Constant step size: Qₙ₊₁ = Qₙ + α·[Rₙ − Qₙ]

Update rules

Return: Gₜ = Rₜ₊₁ + γ·Gₜ₊₁
First-visit MC (averaging): V(Sₜ) ← V(Sₜ) + (1/N(Sₜ))·[Gₜ − V(Sₜ)]
Constant-α MC: V(Sₜ) ← V(Sₜ) + α·[Gₜ − V(Sₜ)]
TD error: δₜ = Rₜ₊₁ + γ·V(Sₜ₊₁) − V(Sₜ)
TD(0): V(Sₜ) ← V(Sₜ) + α·δₜ
True vπ solves Bellman: v(s) = Σₐ π(a|s) Σ p(s′,r|s,a)[r + γ·v(s′)]

What to try

  1. Click Lecture episodes, then Step through them. After episode 4, MC gives Start −1.5, Castle 2.33, Dragon 3.33, and TD(0) gives −1.77, −0.25, 1.68. Castle ends up negative under TD because it bootstraps from V(Dragon), which episode 3 had just pushed down.
  2. Choose Forest (or 50/50) with 2000 episodes. Both methods approach vπ. With α = 0.2, TD keeps jittering around vπ; drop α to 0.02 and it gets smooth but slow. Also try constant-α MC.
  3. Set a pessimistic or optimistic initial V (e.g. +10) and watch how long TD needs to forget it. Sample-average MC overwrites it on the first visit. Lower γ and see the +10 at the Princess lose weight.

Control settings

Update rules

Rewards: −1 per step, −100 for stepping into the cliff (back to start, episode continues)
SARSA (on-policy): Q(S,A) ← Q(S,A) + α·[R + γ·Q(S′,A′) − Q(S,A)], where A′ is the ε-greedy action actually taken next
Q-learning (off-policy): Q(S,A) ← Q(S,A) + α·[R + γ·maxₐ Q(S′,a) − Q(S,A)]
Terminal: Q(goal,·) = 0

What to try

  1. The defaults reproduce Example 6.6: SARSA levels off near −25 per episode, Q-learning near −50. Q-learning's greedy path along the cliff edge is the optimal one, but ε-greedy exploration next to the cliff keeps knocking it in. SARSA learns the values of the policy it actually follows, so it takes the safer upper route.
  2. Turn on ε-decay. As ε goes to 0 both methods approach −13 (the optimal return), and SARSA's path moves toward the cliff too.
  3. Raise ε to 0.3 and watch SARSA's route move further from the cliff. Then try α = 0.1, or γ = 0.9 (with γ < 1 a shorter path is worth more). Press Watch to see one exploratory episode per agent.
